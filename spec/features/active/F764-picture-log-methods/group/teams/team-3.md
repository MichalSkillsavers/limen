# Team 3 · Common operating picture (COP)

Method: The common operating picture (military command posts) with a small fixed symbol set (in the spirit of MIL-STD-2525 / APP-6, much smaller).

Hypothesis: The map is the overview. Each place carries at most one status symbol from a tiny fixed set (for example: changed, at risk, waiting on a decision). The log is the drill-down: one click on a place or symbol opens its dated entries. The first view answers "where is change, where is risk" in one glance. Test whether a symbol set on the graph beats the F763 log column, and where a list must sit beside the map. A mixed style is allowed when a screenshot proves it.

Simplicity check: at most 3 symbols and a one-line legend. Symbols come from model-written values. The build never infers status.
